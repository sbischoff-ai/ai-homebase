Steps:
1. Read `CURRENT.md` and `SURFACES.md`.
2. Create or update `daily/YYYY-MM-DD.md` for the day that is ending now.
3. Write that daily file as a short historical wrap-up in past tense. Do not copy `CURRENT.md` verbatim.
4. Make the daily file clearly historical by covering:
   - what planning or design work happened that day
   - which decisions, open questions, or artifacts still mattered afterward
   - what was explicitly carried forward
5. Rewrite `CURRENT.md` for the new current day, preserving its section structure but carrying forward only still-open planning threads, recent changes that still matter, open design loops, and useful retrieval cues.

Boundaries:
- Keep the daily note compact.
- Do not restate durable plans that already live in Nextcloud.
