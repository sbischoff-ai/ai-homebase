# Daily Notes - Watchdog

Each file here is a historical monitoring wrap-up for one day. Write it in past tense so it cannot be mistaken for `CURRENT.md`.

Capture:
- active incidents or degradations
- baseline changes that still needed follow-through
- upcoming checks or expected windows that remained relevant
- brief references to new monitoring surfaces worth revisiting

Keep live monitoring state in `CURRENT.md`. Promote durable baselines, incidents, and recurring signatures into Nextcloud remote paths or Qdrant.
