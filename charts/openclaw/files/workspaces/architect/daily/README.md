# Daily Notes - Architect

Each file here is a historical planning wrap-up for one day. Write it in past tense so it cannot be mistaken for live planning state.

Capture:
- which project or decision thread was active
- what changed that still mattered afterward
- which open questions were carried forward
- brief references to shared artifacts or surfaces that should be revisited

Keep live planning state in `CURRENT.md`. Promote stable decisions into Qdrant or Nextcloud `/Projects/<slug>/` instead of leaving them here.
