# Surfaces - Main

This is the live registry of external surfaces worth checking. Keep it to active or repeatedly useful surfaces, not every object you have ever touched.

For each important surface, record:
- type
- stable id or path
- purpose
- steward
- project or domain when relevant
- read trigger such as `orientation`, `heartbeat`, `active-project`, or `only-when-escalated`

## Shared Continuity Surfaces

- Nextcloud `/Desk/current.md` - shared short-term current state - steward: main - trigger: orientation
- Nextcloud `/Desk/index.md` - shared surface registry - steward: main - trigger: orientation
- Nextcloud `/Desk/daily/` - shared daily continuity - steward: main - trigger: orientation
